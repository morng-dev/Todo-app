# Todo App

โปรเจกต์ Todo List ที่พัฒนาด้วยตนเอง เพื่อฝึกทักษะการเขียนโปรแกรม การจัดการข้อมูล และการพัฒนาแอปพลิเคชัน

## ฟีเจอร์

- เพิ่มรายการสิ่งที่ต้องทำ
- แสดงรายการสิ่งที่ต้องทำ
- แก้ไขและลบรายการ
- จัดการสถานะของรายการ

## เทคโนโลยีที่ใช้

ระบุภาษาและเครื่องมือที่ใช้จริงในโปรเจกต์นี้

## วัตถุประสงค์

เพื่อฝึกฝนทักษะการพัฒนาซอฟต์แวร์ และสร้างพื้นฐานสำหรับต่อยอดไปสู่โปรเจกต์ที่มีความซับซ้อนมากขึ้น
